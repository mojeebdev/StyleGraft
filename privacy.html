Privacy

Last updated: August 10, 2026.

Skills-only operation

StyleGraft is currently a skills-only plugin. It does not operate an external server, create user accounts, or independently store uploaded screenshots. Inputs are processed within the ChatGPT or Codex product where the plugin is used and remain subject to that product’s applicable privacy terms and workspace settings.

Website

This repository website does not intentionally collect personal information, use advertising trackers, or set analytics cookies.

Future changes

If StyleGraft later introduces server-backed features, this notice will be updated before those features are made available.

Contact

Questions can be raised through GitHub Issues or through BlindspotLab.
